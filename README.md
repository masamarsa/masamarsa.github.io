# MarSa-WebDev

Web制作や日々の試行錯誤を記録する、MarSaの個人サイトです。HTML・CSS・JavaScriptで作られた静的サイトで、ビルド環境は必要ありません。

## 内容

- About: サイトについて
- Focus: Web制作、試行錯誤、記録について
- Views: Webや技術に関する考え
- Now: 現在のサイトについて

## 操作方法

- PCでは、カードをクリックするか、マウスホイールまたは左右の矢印キーでセクションを切り替えます。
- モバイルでは、縦にスクロールしてセクションを移動します。
- ヘッダーの言語メニューから、日本語、アメリカ英語、イギリス英語、オーストラリア英語を選べます。選択した言語はブラウザーに保存されます。

## ローカルで表示する

リポジトリのルートで静的サーバーを起動します。

```sh
python3 -m http.server 8000 --directory docs
```

ブラウザーで <http://localhost:8000> を開いてください。

## ファイル構成

```text
docs/
├── index.html          # サイト本体
├── assets/
│   ├── styles.css      # スタイルとレスポンシブ表示
│   ├── deck.js         # カード・セクションの操作
│   └── language.js     # 言語切り替え
└── ...                 # アイコン、Webアプリマニフェストなど
```

公開する場合は、静的ホスティングサービスで `docs/` ディレクトリを公開対象にしてください。
